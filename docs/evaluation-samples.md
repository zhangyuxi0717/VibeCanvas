# VibeCanvas 输入到导出固定评估样例

用于每次改动后的人工检查。模型输出不能只用字符串断言，需同时查看预览和导出文件。

| 编号 | 场景 | 输入 | 预期 |
|---|---|---|---|
| T1 | 纯文字单页 | “吉他社招新，周六 19:00，学生活动中心” | 文案生成成功；时间和地点只显示用户提供的内容；三套模板均不溢出 |
| T2 | 信息缺失 | “校园摄影展” | 文案可生成；时间、地点、主办方为空，不出现猜测信息 |
| T3 | 上传照片 | JPEG/PNG/WebP 照片 + 可选主题 | 照片预览、替换、移除正常；失败时输入仍保留 |
| T4 | 多页内容 | “期末复习互助周”并选择连续多页 | 返回 3–6 页；封面→内容→结尾；页面信息有推进 |
| T5 | 多页编辑 | 修改第 2 页标题，复制并移动页面 | 预览同步；刷新后文字、顺序和模板恢复 |
| T6 | 长文本 | 接近字段上限的中英文混排、数字、标点和换行 | 页面出现排版检查提示；导出前可人工确认断行，不静默截断 |
| T7 | 生成失败 | 关闭服务或模拟 502/504 | 显示明确错误；输入和已有作品保留；可重试 |
| T8 | 配图部分失败 | AI 配图服务失败或超时 | 文案保留；可导出纯文字或旧图；不会自动重复付费请求 |
| T9 | 批量导出 | 3–6 页，下载 ZIP | 显示真实页码进度；文件按 01、02… 排序；逐页预览与导出一致 |
| T10 | 移动端/键盘 | 窄屏、Tab、Enter、减少动画偏好 | 控件可访问；按钮有焦点反馈；不依赖悬停完成操作 |

## 人工记录

- 文案事实约束：逐项确认时间、地点、主办方没有被模型补写。
- 视觉质量：分别检查极简卡片、大图排版、杂志拼接三个模板。
- 导出质量：检查长标题、英文、数字、特殊符号、缺图提示和字体加载。
- 不将“排版检查提示”描述为完整的视觉质量自动评估。
