# VibeCanvas 传智杯参赛完善实现计划

> **面向 AI 代理的工作者：** 必需子技能：使用 executing-plans 逐任务实现此计划。步骤使用复选框跟踪进度。

**目标：** 修复 VibeCanvas 当前回归、完成本机 ComfyUI/SDXL 真实生图链路，并按传智杯规范生成可复现的参赛材料包。

**架构：** 保留现有 Node 单进程服务、浏览器 IndexedDB 作品库和图片任务执行器；把本机 ComfyUI 作为可选图片后端，通过 API Format workflow 注入英文提示词、轮询历史并读取输出。参赛材料与源码分离，模型运行时和密钥只通过下载/配置说明提供。

**技术栈：** Node.js 20+、原生 Node test、Sharp、ComfyUI API、SDXL Base 1.0、Markdown、PDF/视频材料模板。

**规格：** `docs/superpowers/specs/2026-10-31-vibecanvas-参赛完善-design.md`

## 全局约束

- 参赛目录必须命名为 `传智杯-参赛材料-张瑜唏-12025051277`。
- 不伪造 2026-10-31 之前的 Git 提交、时间戳或 AI 对话截图。
- 参赛材料必须包含 `00` 到 `06` 目录/文件，模型权重和运行时不复制进源码包。
- 本机 ComfyUI 使用 `http://127.0.0.1:8188`，SDXL 输出默认 768×1024、batch 1。
- `npm test`、`npm run build`、`npm run check:config` 必须在最终材料中记录真实结果。
