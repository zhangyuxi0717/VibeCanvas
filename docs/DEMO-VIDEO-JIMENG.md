# 演示视频 · 即梦 AI 提示词

配合 `00_26传智杯_Vibecoding_参赛指导/04_演示视频脚本模板.md` 使用。
项目：VibeCanvas · 校园创意微工坊（把一段校园活动描述变成海报 / 三页小红书图文，支持照片海报、AI 配图、PNG / ZIP 导出）。

---

## 先明确边界：即梦能做什么、不能做什么

模板要求的是 **真实录屏**，不是产品宣传片：

| 段落 | 模板要求 | 能否用即梦生成 |
| --- | --- | --- |
| A 场景与定位（0:00–0:30） | 真实首页，鼠标不动 | 只有片头 3–8 秒空镜可以；首页必须真录 |
| B 核心功能（0:30–2:30） | 真实操作与提示文案 | **不能**。生成界面等于伪造证据 |
| C AI 协同开发（2:30–5:00） | 真实对话、第一次出错、纠偏 | **不能**。这是 20% + 25% 评分的主要载体 |
| D 复现与验证（5:00–6:00） | 真实终端命令与耗时 | **不能** |
| E 结尾（6:00–6:15） | 口播限制与后续 | 最后 3–5 秒空镜可以 |

所以这份提示词只覆盖三类素材：

1. **片头 / 片尾空镜**：宿舍书桌、冲洗照片、打印店、校园公告栏。
2. **演示用示例照片**：喂给 VibeCanvas「照片海报」功能的校园照片，避免使用真人隐私照片。
3. **封面与章节卡背景**：深色紫调、留白，文字后期加。

建议全片 AI 生成画面控制在 **10–15 秒**以内，功能与开发过程全部实拍录屏。即梦生成的画面里不要出现产品界面、聊天窗口或可读文字，否则容易被当成伪造过程。

---

## 统一视觉设定

每个提示词开头都可以复用这段风格锚点，保证几条素材看起来像同一支片子：

```
写实电影感，校园青春题材，低饱和暖色调，自然光，35mm 胶片颗粒，
浅景深，画面干净，无文字，无 logo，无品牌标识
```

品牌色（后期标题卡用）：深色底 `#080A10`，紫罗兰 `#C2B9FB` / `#C3BEFF`，暖橙点缀。

即梦里先生成**首帧图**，确认构图后用「图生视频」，运动幅度选小，镜头固定或缓慢推近。这样比纯文字生成稳。

## 二、演示用示例照片（喂给「照片海报」功能）

这些图会进入 VibeCanvas 的三套照片模板，所以**画面里不要有任何文字、横幅、招牌**，否则会和后期排版打架。人物以侧面、背影为主，不出现清晰正脸。

### P1 · 吉他社招新（4:3）

```
一张真实手机拍摄的校园活动照片：下午的大学草坪，四五个大学生围坐弹吉他，有人打拍子，有人低头笑。自然抓拍，不摆拍，侧逆光，轻微过曝，真实肤色，背景有树和教学楼。4:3 横构图，手机广角，轻微噪点，无文字、无横幅、无 logo。人物以侧面和背影为主，不出现清晰正脸。
```

### P2 · 图书馆读书会（4:3）

```
真实手机照片：图书馆靠窗的木桌，摊开的三本书、一杯咖啡、一支笔和手写笔记，笔记字迹模糊不可读。午后阳光从窗户斜射进来，空气里有轻微尘埃，暖色调，浅景深。4:3 横构图，随手拍质感，轻微噪点，无文字、无 logo。
```

### P3 · 傍晚校园市集（4:3）

```
真实手机夜景照片：傍晚的校园市集摊位，串灯亮起，桌上摆着二手书、黑胶唱片和小盆栽，几名学生低头挑选。暖黄串灯与蓝调天空对比，背景虚化，手机夜景模式质感，轻微噪点。4:3 横构图，无文字、无招牌、无 logo。
```

### P4 · 音乐节观众（3:4，竖版备用）

```
真实手机竖拍照片：校园音乐节傍晚，舞台灯光下的观众背影，几只手举着手机，彩色灯光与暮色天空形成对比。轻微噪点，手机夜景质感，3:4 竖构图，无文字、无 logo、无清晰人脸。
```

## 三、封面与章节卡

### 封面（16:9，用于提交平台缩略图）

```
视频封面，16:9。左侧是深色桌面上的三张紫色系校园海报，纸张有真实阴影和轻微卷边；右侧是傍晚校园公告栏的暖色虚化背景。中间偏左留出大面积干净深色区域，用于后期加标题。紫色与暖橙对比，写实摄影，浅景深，35mm 胶片颗粒，高级、克制，无文字，无 logo。
```

### 章节卡背景（16:9，2 秒静态或 5 秒缓慢循环）

```
深色背景，接近黑色的深蓝紫，几团柔和的紫色渐变光晕缓慢流动，细微胶片颗粒，极简，大量留白，没有主体，没有文字，没有 logo。镜头完全固定，光晕缓慢呼吸。16:9，5 秒。
```

章节文字（A / B / C / D / E）在剪映或 PR 里加，不要交给即梦生成。AI 生成的中文很容易缺笔画或变成乱码，评委一眼就能看出来。

## 四、即梦参数与操作建议

| 项 | 建议 |
| --- | --- |
| 画面比例 | 视频 16:9；示例照片按标注的 4:3 / 3:4 |
| 分辨率 | 1080p 起步，够 1920×1080 成片即可，不必强行 4K |
| 时长 | 单条 5 秒；片头片尾各一条，别生成长镜头 |
| 运动 | 小幅度；固定镜头 + 轻微推近最稳 |
| 生成方式 | 先生成首帧图 → 图生视频，构图更可控 |
| 候选数量 | 每条生成 3–4 个，挑一个，别在第一条上死磕 |
| 负面提示词 | `文字, 汉字, 英文, 水印, logo, 品牌标识, 海报文案, 多余手指, 畸形手, 脸部扭曲, 塑料皮肤, 过度磨皮, HDR, 高饱和, 插画, 3D 渲染, 卡通` |
| 后期 | 统一在剪映 / PR 里调色，加标题与字幕；不要把 AI 素材直接和录屏硬切，留 0.3 秒黑场或直接直切 |

**一致性技巧：** 把同一段「统一视觉设定」放在每条提示词末尾；人物只出现手和背影；场景固定为「傍晚 / 夜晚的校园」，不要一会正午一会深夜。

## 五、和模板时间轴的对应关系

| 时间码 | 模板段落 | 用哪条素材 |
| --- | --- | --- |
| 0:00–0:06 | 片头（可选） | V1 或 V2，配标题卡 |
| 0:06–0:30 | A 场景与定位 | **真实首页录屏**，不要用 AI 画面 |
| 0:30–2:30 | B 核心功能 | **全部真实录屏** |
| 2:30–5:00 | C AI 协同开发 | **全部真实对话录屏**，至少 2 分钟 |
| 5:00–6:00 | D 复现与验证 | **真实终端录屏** |
| 6:00–6:10 | E 限制与后续 | 口播 + 章节卡 |
| 6:10–6:15 | 片尾 | V4，最后停在公告栏 |

如果成片只有 5 分钟出头，优先保 C 段，把片头空镜压到 3 秒甚至去掉。模板里写得很清楚：功能演示 2 分钟够了，AI 开发过程不能少于 2 分钟。

## 六、录制前顺手做的事

- 即梦生成的素材单独放一个文件夹，命名 `v1-desk.mp4`、`p4-market.png`，剪辑时不用猜。
- 所有 AI 素材导出后再检查一遍：有没有莫名其妙的文字、手指、logo。
- 示例照片导入 VibeCanvas 前，确认里面没有学校真实名称、真实人脸、真实手机号。
- 视频里出现的即梦素材不标注「AI 生成」也不会违规，但不要用它冒充产品界面或开发过程。
